monospace fonts), and there are no sound files or raster images from other sources:
the sounds are made in code.

If you contribute a character or other asset, it must be your own work or carry a
permissive license (for example CC0 or MIT). Add it to the table above together
with its license and source.

## Software dependencies

Agent Buddy has one runtime dependency, installed by `npm install` and **not**
included in this repository:

| Package | Version | License | Purpose |
|---|---|---|---|
| [electron](https://github.com/electron/electron) | 45.3.1 | MIT | Runs the overlay window |

Electron's binary download contains Chromium, Node.js and other components under
their own (permissive) licenses. The full list ships with Electron as
`node_modules/electron/dist/LICENSES.chromium.html`.

`npm install` also pulls in these packages, which Electron uses only to download
its binary during installation:

| Package | License |
|---|---|
| @electron/get | MIT |
| @electron-internal/extract-zip | MIT |
| @types/node, undici-types | MIT |
| debug, ms | MIT |
| env-paths | MIT |
| graceful-fs | BlueOak-1.0.0 |
| progress | MIT |
| semver | ISC |
| sumchecker | Apache-2.0 |
| undici | MIT |

All of these licenses are permissive and compatible with distributing Agent Buddy
under the MIT license. None of them is copyleft (GPL/LGPL/AGPL).

`hooks/send.js`, `setup.js`, `uninstall.js` and the scripts in `scripts/` use only
Node.js built-in modules.
